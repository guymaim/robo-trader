# QA evidence

This folder (on the `qa-evidence` branch) holds QA screenshots captured by the Site Checker / senior QA audit of Robo Trader.

Layout: `evidence/<YYYY-MM-DD>-<issue#>-<short-slug>/<filename>`

Screenshots are embedded in the corresponding GitHub issues via
`https://github.com/guymaim/robo-trader/blob/qa-evidence/<path>?raw=true`.

Other users' emails, account IDs and IPs are masked before upload. No secrets are stored here.
