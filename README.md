## What is Robo Trader?

Robo Trader is momentum-style trading software that helps you research, paper-trade, and (when enabled) send orders to **your** [Alpaca](https://alpaca.markets/) or [Interactive Brokers](https://www.interactivebrokers.com/) account.

- **Not a broker** — we never hold your cash or securities.
- **Invite-only** — you sign up, then an admin approves access before trading is enabled.
- **Safeguards** — cash-only position sizing, kill switch, and daily-loss halt on live paths.
- **Transparent** — this public repository is where you learn about the product, follow releases, and talk to us via GitHub Issues.

> Trading equities can result in the loss of principal. Past simulated or live results do not predict future results. Read the risk disclosure on the site before using the product.

## Try it

1. Open **[robo-trader.egedsoft.co.il](https://robo-trader.egedsoft.co.il)**.
2. **Sign in with Google** to request access.
3. Wait for **admin approval** — new accounts stay pending until enabled.
4. After approval, connect your broker and start on **paper** before any live trading.

Full walkthrough: [docs/getting-started.md](docs/getting-started.md).

## Open an issue — we want your feedback

**Please open issues.** Bug reports, feature ideas, unclear docs, and “something feels wrong” notes all help. You do not need to be a developer. If something confused you, that is a valid issue.

We encourage you to:

- Report bugs as soon as you see them
- Request features and improvements
- Ask product questions (use the question template)
- Tell us when the UI or docs are hard to follow

### How to open an issue

1. Go to **[Issues → New issue](https://github.com/guymaim/robo-trader/issues/new/choose)**.
2. Pick a template:
   - **Bug report** — something broke or behaved unexpectedly
   - **Feature request** — an idea or improvement
   - **Question** — how something works, or what to expect
3. Fill in the template. Screenshots and steps to reproduce help a lot.
4. Submit. That is enough — you do not need to fix the code.

More detail: [docs/opening-and-tracking-issues.md](docs/opening-and-tracking-issues.md).

### How to track issues

| What you want | Where to go |
|---|---|
| All open issues | [github.com/guymaim/robo-trader/issues](https://github.com/guymaim/robo-trader/issues) |
| Your issues | [Issues assigned to / created by you](https://github.com/guymaim/robo-trader/issues/created_by/@me) (after you are signed into GitHub) |
| A single issue | Open its page — status, labels, and comments update there |
| What shipped | [RELEASE_NOTES.md](RELEASE_NOTES.md) and [Releases](https://github.com/guymaim/robo-trader/releases) when published |

**Labels** (when present) are a quick status signal:

- `bug` / `enhancement` / `question` — type of request
- `triage` — we have not classified it yet
- `in progress` — someone is working on it
- `blocked` — waiting on more info or an external dependency
- `done` / closed — resolved or declined (check the closing comment for why)

Subscribe to an issue (Watch / Subscribe on the issue page) to get email when there are updates.
