# About this repository

## Purpose

`guymaim/robo-trader` is the **only public** Robo Trader repository. It is for:

- Learning what the product is
- Finding links to try the app
- Opening and tracking **GitHub Issues**
- Reading **release notes**

It intentionally contains **documentation, images, and links** — not application source code.

## What you will not find here

This repo does **not** publish:

- Trading engine or trader source code
- Deployment or hosting details
- Internal operations runbooks
- Credentials or environment configuration

Those stay in private repositories. Product behavior and user-facing changes are described here in plain language.
